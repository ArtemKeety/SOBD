# Online Grocery Delivery — Courier ETA Dataset

## Описание

Датасет для задачи оценки времени прибытия курьера (ETA, Estimated Time of Arrival)
в сервисе онлайн-доставки продуктов.

Каждая строка соответствует одному потенциальному заказу. По набору
анонимизированных признаков (доступность курьеров, гео- и навигационные оценки,
исторические агрегаты по предыдущим доставкам и времени суток) необходимо
предсказать, через сколько минут прибудет курьер.

**Тип задачи:** регрессия
**Целевая переменная:** `delivery_eta_minutes`
**Единица измерения цели:** минуты (float)
**Формат файла:** CSV, разделитель — запятая, десятичный разделитель — точка.

## Структура данных

В выборке **227 колонок**:

| Группа | Колонки | Кол-во | Тип | Описание |
|---|---|---|---|---|
| Числовые признаки | `num_0` … `num_220` | 221 | float | Анонимизированные стандартизованные признаки. Содержат `NaN`. |
| Бинарный признак | `bin_0` | 1 | int (0/1) | Бинарный флаг (например, пиковый/непиковый период, тип зоны или признак заказа). |
| Категориальные признаки | `cat_0`, `cat_1`, `cat_2` | 3 | int | Числовые идентификаторы категорий (локация, зона, тип заказа и т.п.). |
| Временная метка | `timestamp` | 1 | datetime | Момент формирования заказа в формате ISO `YYYY-MM-DDTHH:MM:SS`. |
| Целевая переменная | `delivery_eta_minutes` | 1 | float | Время прибытия курьера в минутах. |

## Признаки

### Числовые признаки `num_0` … `num_220`

- Анонимизированные и стандартизованные (`mean ≈ 0`, `std ≈ 1`).
- Значения, как правило, лежат в диапазоне примерно `[-3, 3]`.
- Во многих колонках присутствуют пропуски (`NaN`) — плотность заполнения
  неоднородна: часть блоков признаков заполнена почти всегда, часть — почти
  всегда пуста. Это следует учитывать при выборе модели (например, использовать
  модели, устойчивые к пропускам, или явно добавлять индикаторы пропусков).
- По смыслу (согласно описанию задачи) эти признаки агрегируют:
  - текущую доступность курьеров в локации;
  - гео- и навигационные оценки времени в пути;
  - исторические агрегаты по предыдущим доставкам (среднее/медиана/квантили);
  - временные характеристики (час суток, день недели, пиковые периоды и т.д.).

### Бинарный признак `bin_0`

Принимает значения `0` или `1`. Точная семантика не раскрыта; в типовых
постановках такого вида соответствует признаку «пиковый час», «выходной»,
«дефицит курьеров» и т.п.

### Категориальные признаки `cat_0`, `cat_1`, `cat_2`

Целочисленные идентификаторы. В предоставленной выборке значения идут
последовательно (1, 2, 3, …), что характерно для кодирования зон, локаций
или типов заказов. Рекомендуется обрабатывать как категориальные
(one-hot / target encoding / embeddings), а не как непрерывные.

### Временная метка `timestamp`

Строка в формате ISO 8601 (`YYYY-MM-DDTHH:MM:SS`). Позволяет извлечь
дополнительные признаки: час, день недели, месяц, признак выходного,
признак пикового периода, а также корректно организовать валидацию
по времени.

### Целевая переменная `delivery_eta_minutes`

Непрерывная величина в минутах. В приведённой выборке значения лежат
в диапазоне примерно **от 1.4 до 17.3 минуты**.
